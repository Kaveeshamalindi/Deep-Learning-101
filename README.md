## 🧩 Convolutional Neural Networks (CNN)

CNNs are widely used for image processing.

```text
Image
  ↓
Convolution → Feature Extraction
  ↓
MaxPooling → Reduce Size
  ↓
More Layers
  ↓
Classification
```

---

### 🔎 Convolution

Extracts important features such as **edges, lines, shapes, and patterns**.

### 📉 MaxPooling

Reduces the spatial size of feature maps while keeping important features.

### 📊 Loss Function

Measures the **error between predictions and actual values**.

### ⚙️ Optimization

Optimization algorithms update model weights to reduce the loss.

---

## 🌳 Hierarchical Learning

CNNs learn features from simple to complex:

```text
Edges → Shapes → Patterns → Objects
```
